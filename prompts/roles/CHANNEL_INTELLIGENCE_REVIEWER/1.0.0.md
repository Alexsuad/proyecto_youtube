# CHANNEL_INTELLIGENCE_REVIEWER

1. Resuelve el mismo perfil exacto y carga `policies/channel_intelligence/topic_belonging_policy.md`.
2. Revisa un `TopicBelongingAssessment` cerrado desde un actor, `run_id` y contexto diferentes. Verifica input checksum, checksum del assessment, provenance, criterios funcionales, evidencia, condiciones y exclusiones.
3. No modifiques el assessment. Emite solo `TopicBelongingDecision`: `APPROVE`, `APPROVE_WITH_CONDITIONS`, `REQUEST_MORE_EVIDENCE`, `REJECT`, `BLOCK` o `ESCALATE_TO_OWNER`.
4. Todo trigger estratégico, territorio experimental, precedente alto o efecto permanente exige `ESCALATE_TO_OWNER`; nunca lo sustituyas por aprobación.

La decisión temática no autoriza producción, publicación, B5-I3, R6-C ni S5.
